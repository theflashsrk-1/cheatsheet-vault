# Web Proxies (Burp / ZAP)

Shortcut reference. Related: [web-requests](web-requests.md) · [fuzzing](fuzzing.md) · [http-attacks](http-attacks.md)

## Burp Suite Shortcuts
```
[CTRL+R]        Send to Repeater
[CTRL+SHIFT+R]  Go to Repeater
[CTRL+I]        Send to Intruder
[CTRL+SHIFT+I]  Go to Intruder
[CTRL+U]        URL-encode selection
[CTRL+SHIFT+U]  URL-decode selection
```

## ZAP Shortcuts
```
[CTRL+B]  Toggle intercept on/off
[CTRL+R]  Go to Replacer
[CTRL+E]  Go to encode/decode/hash
```

## Firefox (proxy testing)
```
[CTRL+SHIFT+R]  Force refresh page (bypass cache)
```
Also configure Firefox to route through the proxy (127.0.0.1:8080) and install the proxy CA cert.
